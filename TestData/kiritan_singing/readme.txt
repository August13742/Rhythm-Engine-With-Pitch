東北きりたん歌唱データベース（Tohoku Kiritan singing database)
以下では「きりたん歌唱DB（Kiritan singing DB）」とします．

-- 内容
きりたん歌唱DBは，アニメソングやポップス楽曲を対象とした歌唱データとラベルデータから構成されます．
茜屋日海夏氏が演ずる東北きりたんの声により，50曲分（有声区間で約58分）収録しました．
収録はレコーディングスタジオで，Neumann u87ai（単一指向性）を用いて96 kHz/24 bitで実施しました．
各楽曲につき，1番を中心に約1分程度の量を収録しています．

 - /wav/ 		... 音声波形
 - /mono_label/ 	... 音素のラベル情報
 - /midi_label/		... 譜面のラベル情報
 - list.xlsx 		... 収録楽曲リスト
 - noise.txt 		... 収録音声中に含まれるノイズの情報
 - japanese.table 	... 辞書ファイル

-- 音素ラベル付けについて
Juliusにより自動設定後，主担当者，副担当者により詳細なラベル付けを実施し，
その後，主担当者1名が再度手動で微調整しました．
歌詞よりも発音に沿った音素を当てはめているため，歌詞と異なっている部分があります．
また，子音よりも母音を長めにとっています．

-- japanese.tableについて
japanese.tableは辞書ファイルとなっており，Sinsyの辞書ファイルとほぼ同様のものを使用しています．
ただし，このデータベースに含まれている変換規則のみをSinsyの辞書ファイルから抽出して作成しています．
また，「を」については，Sinsyとは異なり「/w/o/」と定義しています．
